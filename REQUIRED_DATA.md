- **Текущее значение:** "+7 (XXX) XXX-XX-XX" (placeholder)

- **Где используется:** Секция "Свяжитесь с нами" и футер

#### Часы работы

### 3. 🍽️ МЕНЮ РЕСТОРАНА

**Текущее состояние:** Меню полностью пустое (все категории пустые)

#### Структура данных для каждого блюда:

```javascript
{
  id: "уникальный-id",           // Уникальный идентификатор
  name: "Название блюда",        // Название на всех языках (или основное название)
  description: "Описание...",    // Описание блюда
  price: "25 AZN",              // Цена (можно в любой валюте)
  category: "appetizers",        // Категория: "appetizers", "main", "desserts", "sets"
  
  // Опциональные поля для AI-помощника:
  tags: ["острый", "мясо"],     // Теги для поиска
  spicy: true/false,            // Острое блюдо?
  meat: true/false,             // Содержит мясо?
  fish: true/false,             // Содержит рыбу?
  vegetarian: true/false,       // Вегетарианское?
  light: true/false             // Легкое/диетическое?
}
```

#### Категории меню:

1. **Закуски (Appetizers)** - `appetizers`
   - Нужно предоставить: список закусок с названиями, описаниями и ценами

2. **Основные блюда (Main Courses)** - `main`
   - Нужно предоставить: список основных блюд с названиями, описаниями и ценами

3. **Десерты (Desserts)** - `desserts`
   - Нужно предоставить: список десертов с названиями, описаниями и ценами

4. **Сеты (Sets)** - `sets`
   - Нужно предоставить: список сетов/комплексных обедов с названиями, описаниями и ценами

#### Формат предоставления меню:

Вы можете предоставить меню в любом удобном формате:
- Excel/CSV файл
- Текстовый файл
- Просто списком в сообщении
- JSON формат (если удобно)

**Минимально необходимая информация для каждого блюда:**
- Название
- Описание (желательно)
- Цена
- Категория

**Дополнительно (для улучшения работы AI-помощника):**
- Теги (острый, мясо, рыба, вегетарианское, легкое и т.д.)
